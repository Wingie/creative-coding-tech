What I’m building

Agentosaurus

A site that helps people find groups working on climate. AI agents write most of its code. In 2026 they opened and merged over a thousand pull requests. They never message each other. They read each other’s code reviews instead.

Django · Claude Code · k3s · Own GPUs

Proving what a model learned from

If someone fine-tunes a model on your data, can you prove it afterwards? I plant keyed markers in the training set. Later you can test any model and show, mathematically, whether it learned from that data.

Model provenance · Fine-tuning · Evaluation

Psychohistory

Three years asking whether you can forecast crowd behaviour like weather. One prediction passed a sealed test. Several others failed, and I published those too.
